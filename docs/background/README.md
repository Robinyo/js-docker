# ❯ Background

The official JasperReports Server Community Edition was abruptly discontinued and deleted by Cloud Software Group 
(TIBCO/Jaspersoft). Following this mass deletion of the AGPL-licensed repositories, the open-source community stepped 
in to preserve, archive, and maintain independent community forks of the source code.

## Active Community Forks & Archives

- jasper-server-os: This is currently the most prominent community-driven fork. Initiated by developer José da Silva, it 
aims to maintain and tweak the community edition code. It provides independent community installer binaries (up to 
versions 8.3 and 8.4) via the JasperReports Community Installers SourceForge and hosts its source files directly on the 
[jose-da-s/jasper-server-os](https://github.com/jose-da-s/jasper-server-os) GitHub Repository.
- OpenJasper: Organized immediately following the deletion of the official projects, the 
  [neuralnexus/OpenJasper](https://github.com/neuralnexus/OpenJasper) GitHub Repository functions as an open-source hub 
  to aggregate and preserve the original AGPL-licensed server, client, and related source files recovered from public 
  caches.
- jasperreports-server-ce: A highly-cloned preservation repository hosting the older source versions can be found at the 
[suncoderus/jasperreports-server-ce](https://github.com/suncoderus/jasperreports-server-ce) GitHub Repository.
